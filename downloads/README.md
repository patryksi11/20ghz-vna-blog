# Downloads

Drop downloadable measurement files here (e.g. CSV, S2P, screenshots).

Link to them from posts like this:

```markdown
Download the raw data: [s11_1-20ghz.csv]({{ site.baseurl }}/downloads/s11_1-20ghz.csv)
```

Keep files reasonably small (GitHub has a 100 MB per-file hard limit; stay well below it).
